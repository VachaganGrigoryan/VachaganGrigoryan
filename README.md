## About Me
I'm **Vachagan Grigoryan**, a **Senior Software Engineer** based in **Yerevan, Armenia**, with over 6 years of experience specializing in backend development using Python and TypeScript. I'm skilled in modern frameworks such as Django, FastAPI, Strawberry GraphQL, Nest.js, and Express.js, with hands-on exposure to Go and Rust, and I have a proven track record of delivering scalable software solutions across fintech, blockchain, and e-commerce. I'm also experienced in frontend development with Next.js and Tailwind CSS, and I'm passionate about clean architecture, automation, and building performant, maintainable systems.

More recently, I've been working hands-on with AI-native and AI spec-driven development — using tools like Claude Code to build and ship software through structured, spec-first workflows. I'm actively building agentic systems with LangChain and LangGraph, integrating Model Context Protocol (MCP) servers, and applying Retrieval-Augmented Generation (RAG) to ground LLMs in real data.
